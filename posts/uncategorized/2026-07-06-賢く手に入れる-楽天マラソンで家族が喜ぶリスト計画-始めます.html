賢く手に入れる！楽天マラソンで家族が喜ぶリスト計画、始めます

2026-07-06 | OBSERVATION
週末、子供たちが公園で元気に遊んでいるのをベランダから眺めていると、ふと、先月の楽天お買い物マラソンのことを思い出しました。あの時も「お得に！」と思って勢い込んだものの、結局何が一番お得だったのか、いまいち手応えがなくて。

「また失敗したな…」と、ちょっとため息が出そうになります。お得なはずの楽天マラソンなのに、蓋を開けてみれば、不要なものまで買ってしまって予算オーバー。家族の欲しいものもバラバラで、結局自分のものばかり買って罪悪感を感じてしまう。そんな経験、私だけではないですよね。

でも、そろそろこのモヤモヤを解消したいんです。家族みんなが笑顔になれて、しかも賢くポイントを稼げる、そんな楽天マラソンの「賢い戦略」を、我が家で本格的に始めてみようと思います。その第一歩として、週末の家族会議で「欲しいものリスト」を作ることにしたんです。

「10店舗買い回り神話」はもう古い！我が家のSPU＆ふるさと納税戦略

「楽天マラソンは10店舗買い回りが絶対お得！」という話、よく耳にしますよね。私も以前は、無理に1,000円ポッキリの商品を買い増して、どうにか10店舗達成しようとしていました。でも、ある時気づいたんです。無理に不要なものを買うより、本当に必要な高額商品を数店舗で買う方が、結果的にポイントが多くつくケースがあるって。

例えば、5万円以上の家電を5店舗目で買った場合と、1,000円の商品を無理に10店舗買ってポイントを稼ぐ場合では、高額商品の方が得られるポイント額が数倍大きくなることがあるんです。大切なのは、無理なく、賢く、必要なものを買うこと。

我が家では、まずSPU（スーパーポイントアッププログラム）をしっかり確保することを目標にしています。
最低限、この2つは外せません。

  • 楽天モバイル契約で+2倍
  • 楽天カード利用で+2倍

これだけで、基本ポイントを含めてもかなりの還元率になります。

そして、買い回りの店舗数を効率的に増やすために活用するのが、楽天ふるさと納税です。10,000円以上の寄付を複数店舗に分散させることで、無理なく店舗数を稼ぐことができます。例えば、お米や日用品、ご当地グルメなど、家族で相談して「これいいな」と思ったものをいくつか選ぶんです。

具体的なポイント還元率の例を見てみましょう。

| 項目 | 倍率 |
| :------------------- | :--- |
| 通常ポイント | 1倍 |
| 楽天モバイル | +2倍 |
| 楽天カード | +2倍 |
| 楽天証券（ポイント投資） | +1倍 |
| 楽天銀行（楽天カード引落） | +1倍 |
| 楽天ひかり | +1倍 |
| 楽天トラベル | +1倍 |
| 楽天ブックス | +0.5倍 |
| 楽天Kobo | +0.5倍 |
| 楽天Pasha | +0.5倍 |
| 楽天ファッション | +0.5倍 |
| 楽天ビューティ | +0.5倍 |
| 買い回り（10店舗達成） | +9倍 |
| 合計 | 最大16倍（SPU） + 9倍（買い回り） = 25倍 |

これに、ショップごとの個別ポイントアップや、5と0のつく日の利用、勝ったら倍キャンペーンなどを組み合わせると、最大39倍も夢ではありません。特に、Panasonicドラム式洗濯乾燥機 NA-VX900BLのような高額家電を買うタイミングでこの戦略を実践できれば、得られるポイントは本当に大きくなります。

家族が「前のめり」になる！15分で完了する「爆速欲しいものリスト」作成術

家族の欲しいものがバラバラで、意見がまとまらない…という悩み、よく聞きます。我が家もそうでした。でも、最近始めた「週末15分間の家族会議」が、驚くほど効果的なんです。

毎週土曜日の夜、夕食後にちょっとしたデザートを用意して、リビングに集合。会議のルールはシンプルです。

  1. 一人3つまで、本当に欲しいものをリストアップする。
  2. 価格は問わないが、必要性を簡単に説明する。
  3. 他の家族の意見も尊重する。

例えば、夫は「ゴルフボール3ダース」や「新しいランニングシューズ」、私は「SK-IIフェイシャルトリートメントエッセンス」や「ちょっといいフライパン」、子供たちは「レゴシティシリーズの新作」や「新しい図鑑」など、それぞれが本当に欲しいものを口に出します。

この会議、最初は「面倒だな」と思うかな、と心配しましたが、デザート効果もあってか、みんな結構前のめりになってくれるんです。特に子供たちは、自分の欲しいものを真剣に考えて発表するのが楽しいみたいで。「それいる？」なんて言い合いになることもありますが、それも含めてコミュニケーションですよね。

余談ですが、先日、夫がリストに「新しいキャンプ用チェア」を入れてきたんです。私も気になっていたので「いいね！」と盛り上がったんですが、子供たちが「それより先に、壊れてる自転車の修理！」と猛反対。結局、自転車修理が優先順位の上位に繰り上がりました（笑）。こういう風に、家族みんなで優先順位を考えるのも大事だな、と改めて感じましたね。

この15分で、家族みんなの「欲しいもの」が見える化され、次のマラソンで何を買うべきか、方向性が明確になります。

ポイント爆益＆家族満足度MAX！我が家の「最終購入計画」と、あなたへの本音エール

さて、いよいよ最終的な購入計画です。リストアップした欲しいものと、SPU・ふるさと納税戦略を組み合わせます。

我が家では、こんな感じで計画を立てています。

  1. ふるさと納税で店舗数を稼ぐ * まず、家族の欲しいものリストの中から、ふるさと納税の返礼品として選べるもの（お米、お肉、果物など）を複数店舗に分散させて寄付します。10,000円以上の寄付を意識して、効率よく店舗数を増やします。
  2. 日用品で隙間を埋める * 次に、普段から使う日用品で1,000円以上の商品を探します。例えば、「花王アタックZERO 詰め替え2kg」や「クリスタルガイザー500ml×48本」など、消耗品はいくらあっても困りません。これらで買い回り店舗数をさらに増やします。
  3. 高額商品を最後の店舗で！ * そして、リストの中で一番高額な商品、例えば「Panasonicドラム式洗濯乾燥機 NA-VX900BL」のような家電を、最後に購入する店舗に設定します。こうすることで、これまでの買い回りで積み上がったポイント倍率が、一番大きな買い物に適用され、最大のポイント還元を得られるというわけです。

「ついつい不要なものまで買ってしまい、気づけば予算オーバー」という悩みも、この計画術で解決できます。家族会議で決めたリストにないものは買わない、と徹底するんです。そして、あらかじめ予算上限を明確に設定しておくことも大切です。

楽天マラソンは、ただのセールイベントではありません。家族のニーズを満たし、家計を助けるための戦略的な買い物イベントなんです。複雑そうに見えても、今回ご紹介したように、少しの工夫と事前の計画で、ぐっとお得に、そして家族みんながハッピーになれる買い物ができますよ。

次の楽天マラソンでは、ぜひ家族で「欲しいものリスト会議」を開いてみてください。きっと、これまでとは違う、充実したお買い物体験ができるはずです。私も、食卓革命の一環として、この賢約術をさらに磨いていきたいと思っています。あなたも、一緒に頑張りましょうね！
